# 暖炉到家 NuanLu

> 农村家用燃煤取暖炉一站式选购小程序 —— **买炉子、配零件、约安装**，一个小程序全搞定。

## 项目简介

面向农村家庭取暖场景的微信小程序，解决「不知道买哪种炉子、配件买不齐、装炉子找不到人」的问题：

- **采暖炉商城**：按房屋面积/系列/价格挑选燃煤采暖炉，支持智能选炉
- **配件耗材**：烟囱、暖气片、水泵、阀门、密封材料等一站式配齐
- **上门安装**：在线预约师傅，透明收费，安装进度全程可追踪

纯前端演示版本，全部数据为本地模拟数据，无后端依赖，导入即可运行。

## 功能模块

### 首页
- 搜索栏（按型号 / 取暖面积搜索）
- 三大核心入口：燃煤采暖炉 / 配件耗材 / 安装服务
- 促销轮播 Banner、热销推荐横滑
- 「1 分钟按面积匹配」智能选炉入口

### 采暖炉商品列表
- 系列筛选：全部 / 直烧款 / 气化款
- 排序：综合推荐 / 销量 / 好评 / 价格（升降序切换）
- 面积筛选面板：50-80㎡ / 80-120㎡ / 120-160㎡ / 160㎡以上
- 双列大卡片，价格红色醒目，显示包邮/包安装标签
- 上拉触底分页加载（加载中 / 没有更多了）
- 适老化设计：大字号、大间距、点击热区 ≥88rpx

### 配件耗材
- 左侧 8 大分类栏（烟囱管道 / 暖气片 / 水泵 / 循环泵 / 阀门管件 / 密封材料 / 温控器 / 工具类）
- 右侧商品列表，**左右双向联动**（点分类右侧滚动，右侧滚动左侧自动高亮）
- 顶部关键词搜索（跨分类）
- 加购按钮 + 右下角浮动购物车（角标 + 弹跳动画）

### 安装服务
- 服务保障说明（4 项承诺）
- 透明收费标准（基础安装免费 / 加长烟道 / 打孔 / 楼层费）
- 关联已购订单（仅「已签收」可预约），选择后自动带入地址
- 未来 7 天日历选择（约满日期置灰不可选）
- 上午 / 下午时间段
- 五步安装进度追踪：待接单 → 已接单 → 已出发 → 安装中 → 安装完成
- 师傅接单后展示师傅姓名、评分、单量，可一键拨打电话

### 其他页面
- **智能选炉**：输入取暖面积 + 房屋保温情况，按功率推荐合适型号
- **商品详情**：参数、服务、下单、客服电话
- **我的**：安装预约记录、选购清单数量、客服入口

## 技术架构

- 微信小程序原生开发（WXML + WXSS + JavaScript）
- 无后端，数据在 `data/mock.js` 本地模拟
- 图标使用 GDI+ 本地绘制的 PNG（`images/`），零网络依赖
- 主题色：暖橙 `#FF6B35`，价格红 `#F0382F`，背景浅灰 `#F5F5F5`

## 目录结构

```
nuanlu/
├── app.js / app.json / app.wxss     # 全局入口、路由与 Tab、暖橙主题
├── project.config.json              # 项目配置
├── data/
│   └── mock.js                      # 模拟数据：炉子/配件/订单/收费/进度
├── images/                          # 导航图标、搜索、购物车图标（本地 PNG）
├── utils/
│   └── format.js                    # 金额格式化、按面积智能选炉
└── pages/
    ├── index/                       # 首页（搜索+3入口+轮播+热销）
    ├── stove-list/                  # 采暖炉列表（筛选/排序/分页）
    ├── parts/                       # 配件耗材（左右联动+搜索+加购）
    ├── install/                     # 安装服务（预约+进度追踪）
    ├── picker/                      # 智能选炉
    ├── detail/                      # 商品详情
    └── my/                          # 我的
```

## 快速开始

1. 下载安装[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 导入项目，目录选择本仓库根目录
3. AppID 选择「测试号」即可在模拟器体验
4. 如需手机真机预览：注册个人小程序获取真实 AppID 填入 `project.config.json`，点工具栏「预览」扫码

## 数据说明

当前为 v1 演示版：
- 所有商品、订单、预约数据均为本地模拟，存储在小程序 Storage
- 支付、电话、消息通知均为模拟动作（`wx.makePhoneCall` 拨打的是占位号码）
- 接入真实业务时，将 `data/mock.js` 的数据来源替换为云开发 / 后端接口即可，页面逻辑无需改动
